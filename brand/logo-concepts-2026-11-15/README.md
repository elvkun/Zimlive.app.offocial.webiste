# Flow and O’Riley Platforms — logo concepts v1

Created 15 November 2026 with the built-in image-generation tool. These are new concepts, not a replacement of the current live branding.

- Flow: fluid ribbon f, expressing movement and connection.
- O’Riley Platforms: architectural open-ring O, expressing a platform supporting connected ventures.
- Palette direction: forest #0B3B2F, pine #006C49, emerald #10B981. Generated raster colors contain tonal variation; these are palette references, not exact per-pixel restrictions.
- Each brand folder contains a transparent 1254 × 1254 PNG symbol, a horizontal SVG container with embedded raster symbol and outlined Noto Sans lettering, and the exact generation prompt.
- The SVG wordmarks are hybrid raster/vector files, not fully vector logos. Lettering is outlined and requires no installed font. Symbol detail remains resolution-limited.
- Open preview.html directly to view both concepts. PNG is the most widely supported import format for social platforms, presentation tools and design editors. SVG support varies by service; app stores may require flattened backgrounds, exact dimensions or additional review.
- Keep at least one fifth of the symbol width clear around it. Use the green assets on white or pale mint. Check contrast and legibility at the actual display size; no minimum-size or app-store acceptance certification is claimed.
- Transparent pixels must stay transparent when imported. Keep the original PNG masters. Do not stretch proportions.
- Separate API/native/platform feature claims are not part of this artwork. No trademark search or clearance was performed.

The assets are stored in repository brand/ directories as reusable source materials. They are not automatically included in the Foundation public dist allowlist or wired into production interfaces.
