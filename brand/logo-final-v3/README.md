# Final reusable logos — v3

Owner-approved wording, 15 November 2026:

F / Flow / IDEAS IN MOTION

O / O’Riley Foundation / PRODUCTS WITH PURPOSE

Only these two identities are current. The older O’Riley Platforms-named variant is archived and should not be used for new branding.

## Visual system

Forest green #0B3B2F, muted text #414945 and quiet off-white #F7FAF8. Compact 48 px horizontal brand names, restrained 14 px tracked taglines, generous spacing. No shadows, gradients, extra slogans, bright accents or decorative claims. Reversed logos use white lettering on a dark background. Lettering is outlined Noto Sans Bold; all SVG shapes are native vectors.

## Choose a file

- horizontal: full name and exact tagline for websites, documents and email layouts. Transparent SVG and PNG.
- horizontal-reversed: white full logo for dark backgrounds. Transparent SVG and PNG.
- stacked: full logo on a square transparent canvas for larger placements where the tagline remains readable.
- profile-1024 / profile-512: exact-size square PNGs plus scalable SVGs containing only F or O. The mark occupies the central 64% so it remains clear in a circular crop. Use these for social profile pictures. Put the full name and tagline in the account name/bio or cover rather than squeezing tiny wording into an avatar.
- social-cover: neutral 1600 × 900 SVG composition, also exported as 3200 × 1800 PNG. Use as a reusable starting point and crop/resize for the target service. This is not a promise of compliance with every platform’s current cover dimensions.

Every full logo includes the exact approved wording as part of its vector artwork. File dimensions are listed in manifest.json. Do not stretch assets. Check final display size and contrast; tiny full logos can make the tagline unreadable.

Open preview.html locally. build_logos.py reproduces exports using system Noto Sans Bold, fontTools, librsvg and Cairo. No image-generation model was used for these native vector revisions. No trademark clearance, live deployment, account creation or social publication was performed. Previous versions remain archived.
