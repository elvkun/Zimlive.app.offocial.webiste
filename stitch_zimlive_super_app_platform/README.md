# Flow interface assets

This folder contains the Flow interface previews and their Stitch source designs.

## Account and mobile app links

The sign-in and create-account controls in the HTML previews link to the account section on `https://zimlive.app/#account-access`. Account creation and sign-in happen on the Flow website; the standalone previews do not collect credentials or implement authentication themselves.

The Apple App Store and Google Play badges open store search pages for Flow by O’Riley Foundation. These are search links because stable direct listing URLs are not yet available.

The `screen.png` files are original design reference captures. The HTML source is the current interactive preview and may not match every detail in those earlier captures.
